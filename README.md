TubeLens leverages cloud-based video processing and event-driven architecture to media workflows and accelerate data analysis for intelligent applications.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TubeLens.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

TubeLens is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
